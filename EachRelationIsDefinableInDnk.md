# План доказательства классификации бинарных отношений

Для `k ≥ n ≥ 0` обозначим через `D_(k,n)(x,y)` отношение

```text
y - x ∈ {(±k,±n),(±n,±k)}.
```

Рассматривается определимость без параметров: в формуле не используются
заранее выбранные точки решётки.

Предполагаемое утверждение: каждое бинарное отношение, определимое в
`<Z²,E>`, является либо конечным объединением отношений `D_(k,n)`, либо
дополнением конечного объединения таких отношений.

## План доказательства

1. Для каждого фиксированного `k,n` отношение `D_(k,n)` определимо через `E`.
   Это даёт определимость любого конечного объединения таких отношений и его
   дополнения.

2. Переносы, повороты на угол, кратный `90°`, и отражения сохраняют `E`.
   Поэтому они сохраняют любое отношение, определимое через `E`. Любые две пары
   точек одного типа `D_(k,n)` переводятся друг в друга одним из таких
   преобразований. Следовательно, определимая формула имеет постоянное значение
   на каждом `D_(k,n)`.

3. Пусть бинарное отношение задаётся FO-формулой `φ(x,y)`. По
   [теореме Гайфмана 4.22 в книге Леонида Либкина *Elements of Finite Model Theory*](https://homepages.inf.ed.ac.uk/libkin/fmt/fmt.pdf)
   эта формула равносильна конечной булевой комбинации:

   - локальных формул вокруг `(x,y)`;
   - предложений без свободных переменных, утверждающих существование нескольких
     достаточно удалённых точек с заданным локальным свойством.

4. Для фиксированной решётки предложения без свободных переменных имеют
   постоянные значения и не различают пары `(x,y)`. Поскольку булева комбинация
   конечна, среди радиусов всех её локальных формул существует максимальный
   радиус `r`.

5. Если `d(x,y) > 2r+1`, шары радиуса `r` вокруг `x` и `y` не пересекаются и
   между ними нет рёбер. Поэтому окрестность пары `(x,y)` является объединением
   двух отдельных одинаковых шаров с отмеченными центрами.

6. Окрестности радиуса `r` любых двух пар, расстояние внутри которых больше
   `2r+1`, изоморфны с сохранением отмеченных `x` и `y`. Все локальные части
   формулы, а значит и `φ`, имеют на таких парах одно общее значение.

7. Для пары типа `D_(k,n)` расстояние по клеткам равно `k+n`. При
   `k+n ≤ 2r+1` существует лишь конечное число пар целых чисел
   `k ≥ n ≥ 0`. Поэтому отдельно формула может выбирать только конечное число
   типов `D_(k,n)`; на всех остальных типах её значение одинаково.

8. Если общее значение на достаточно далёких парах ложно, определяемое
   отношение является конечным объединением `D_(k,n)`. Если оно истинно,
   дополнение определяемого отношения является конечным объединением
   `D_(k,n)`.

## Отношения большей арности

Предыдущее утверждение непосредственно классифицирует только бинарные
отношения. Для отношения

```text
R(x₁,...,xₘ)
```

нужно учитывать не только расстояние между одной парой точек, но и взаимное
расположение всех точек кортежа.

Полезный образец даёт работа А. Л. Семёнова и С. Ф. Сопрунова
[*Lattice of relational algebras definable in integers with successor*](https://arxiv.org/abs/1201.4439)
([опубликованная версия](https://www.mathnet.ru/eng/im9107)). В её лемме 6
доказывается аналог следующего принципа: у каждого определимого отношения есть
конечная ширина. После некоторой границы формула перестаёт различать точные
расстояния и видит только то, какие элементы расположены близко друг к другу.

Приведённый ниже план является переносом этой идеи на `<Z²,E>`, а не
утверждением из самой статьи.

### 1. Лемма о ширине

Для каждого определимого отношения `R(x₁,...,xₘ)` нужно доказать существование
числа `w` со следующим свойством. Если отмеченные `w`-окрестности двух кортежей

```text
(x₁,...,xₘ) и (y₁,...,yₘ)
```

изоморфны, причём каждая отмеченная точка `xᵢ` переходит в `yᵢ`, то

```text
R(x₁,...,xₘ) ⇔ R(y₁,...,yₘ).
```

Для структуры `<Z²,E>` это следует из теоремы Гайфмана: предложения без
свободных переменных имеют в фиксированной решётке постоянное значение, а среди
радиусов локальных частей формулы можно выбрать наибольший.

### 2. Разбиение переменных на близкие группы

Для кортежа `(x₁,...,xₘ)` построим конечный граф на номерах переменных:

```text
i соединено с j ⇔ d(xᵢ,xⱼ) ≤ 2w+1.
```

Компоненты связности этого графа назовём близкими группами. Точки из разных
групп имеют непересекающиеся `w`-окрестности, между которыми нет рёбер.

Например, для трёх переменных возможны разбиения

```text
{x}, {y}, {z};
{x,y}, {z};
{x,z}, {y};
{y,z}, {x};
{x,y,z}.
```

### 3. Тип конфигурации целой группы

Для двух точек тип задаётся одним отношением `D_(k,n)`. Для трёх и более точек
нужно описывать всю конфигурацию одновременно. Нельзя независимо выбирать
поворот или отражение для каждой пары: одно геометрическое преобразование должно
действовать сразу на всю близкую группу.

Пусть `v₂,...,vₛ` — фиксированные векторы. Обозначим через
`T_(v₂,...,vₛ)(x₁,...,xₛ)` следующий тип конфигурации:

```text
существует один поворот или отражение g такой, что
xᵢ - x₁ = g(vᵢ) для всех i = 2,...,s.
```

При `s=2` получается бинарный тип `D_(k,n)`. Таким образом, отношения `T`
являются естественными многоместными аналогами `D_(k,n)`.

Это пока геометрическое обозначение типа. Его определимость через `E` нужно
доказывать отдельно для каждой фиксированной конечной конфигурации, описывая её
ограниченную отмеченную окрестность.

### 4. Почему типов конечное число

В одной близкой группе находится не более `m` точек. Между соседними точками
графа группы расстояние не превосходит `2w+1`. Поэтому диаметр группы не
превосходит

```text
(m-1)(2w+1).
```

В шаре ограниченного радиуса решётки находится конечное число точек.
Следовательно, для фиксированных `m` и `w` существует только конечное число
типов близких отмеченных конфигураций с точностью до переноса, поворота и
отражения.

Отсюда ожидается следующая нормальная форма для любого `m`-местного отношения:

```text
разбиение переменных на близкие группы
+ тип конфигурации каждой группы
+ условие, что разные группы достаточно далеки.
```

Само отношение является конечным объединением таких случаев.

### 5. Переход к решётке определимости

Нормальная форма описывает отдельное отношение, но ещё не определяет его место
в решётке определимости. Следующий этап по образцу Семёнова и Сопрунова:

1. Зафиксировать произвольное определимое отношение `R`.
2. Выбрать для него ширину `w`.
3. Определить, какие конечные конфигурации различает `R`.
4. Рассмотреть перестановки точек, сохраняющие `R`.
5. Проверить, сохраняют ли эти перестановки некоторое бинарное отношение
   `D_(k,n)`.
6. Если подходящего `D_(k,n)` нет, искать новый действительно многоместный
   базовый тип отношения.

Поэтому пока нельзя утверждать, что каждое отношение большей арности взаимно
определимо с некоторым бинарным `D_(k,n)`. Это отдельное утверждение, которое
нужно доказать или опровергнуть.

## Ограниченные многоместные отношения

Ниже разбирается частный случай, в котором многоместное отношение имеет
ограниченный диаметр. В этом случае отношение можно свести к бинарному, а затем
к одному из канонических отношений $DS_d$ или $DD_d$.

### 1. Канонические бинарные отношения

Для $d\geq 1$ обозначим через $DS_d$ прямое решёточное отношение

$$
DS_d(x,y)
\quad\Longleftrightarrow\quad
y-x\in\{(\pm d,0),(0,\pm d)\},
$$

а через $DD_d$ — диагональное решёточное отношение

$$
DD_d(x,y)
\quad\Longleftrightarrow\quad
y-x\in\{(\pm d,\pm d)\}.
$$

Во втором определении знаки выбираются независимо, то есть допустимы четыре
вектора $(d,d)$, $(d,-d)$, $(-d,d)$ и $(-d,-d)$.

Класс достижимости нуля для $DS_d$ равен

$$
L(DS_d)=d\mathbb Z^2,
$$

а для $DD_d$ равен

$$
L(DD_d)
=
dP,
\qquad
P=\{(a,b)\in\mathbb Z^2:a\equiv b\pmod 2\}.
$$

Каждая компонента любого из этих отношений изоморфна обычной квадратной
решётке.

### 2. Определение ограниченности

Пусть $R(x_1,\ldots,x_m)$ определимо без параметров в
$\langle\mathbb Z^2,E\rangle$. Назовём $R$ ограниченным, если существует
$r\in\mathbb N$ такое, что

$$
R(x_1,\ldots,x_m)
\quad\Longrightarrow\quad
d_E(x_i,x_j)\leq r
$$

для любых $i,j\in\{1,\ldots,m\}$.

Иначе говоря, множество различных точек каждого кортежа из $R$ имеет
равномерно ограниченный диаметр.

### 3. Бинарное отношение совместной встречаемости

Для ограниченного отношения $R$ определим бинарное отношение $B_R$:

$$
\begin{aligned}
B_R(u,v)
\quad\Longleftrightarrow\quad&
u\neq v\ \land\\
&\bigvee_{i\neq j}
\exists z_1\cdots\exists z_m\,
\bigl(R(z_1,\ldots,z_m)\land z_i=u\land z_j=v\bigr).
\end{aligned}
$$

В этой записи дизъюнкция берётся по конечному множеству упорядоченных пар
$i\neq j$. Поэтому это обычная конечная формула первого порядка. В частности,
$B_R$ определимо через $R$.

Включение всех упорядоченных пар индексов делает $B_R$ симметричным, даже если
само отношение $R$ несимметрично по своим переменным.

### 4. Все элементы одного $R$-кортежа лежат в одной компоненте $B_R$

Пусть

$$
R(x_1,\ldots,x_m).
$$

Возьмём два различных значения $u$ и $v$, встречающихся в этом кортеже.
Существуют индексы $i\neq j$, для которых $u=x_i$ и $v=x_j$. В определении
$B_R(u,v)$ положим $z_\ell=x_\ell$ для всех остальных индексов. Исходный
кортеж является требуемым свидетелем, поэтому

$$
B_R(u,v).
$$

Следовательно, различные значения, встречающиеся в одном $R$-кортеже,
образуют клику в графе $B_R$. В частности, они лежат в одной компоненте
связности этого графа.

Компонента здесь используется как внешнее теоретико-графовое понятие. Не
утверждается, что отношение «лежать в одной компоненте» определимо одной
формулой первого порядка. Для дальнейшего рассуждения достаточно того, что
любой автоморфизм графа переводит конечные пути в конечные пути и потому
переставляет его компоненты связности.

### 5. Почему $B_R$ является конечным объединением отношений $D_{a,b}$

Из ограниченности $R$ следует

$$
B_R(u,v)\quad\Longrightarrow\quad d_E(u,v)\leq r.
$$

Кроме того, $B_R$ определимо через $E$, поскольку $R$ определимо через $E$.
Следовательно, $B_R$ сохраняется всеми переносами, поворотами на углы,
кратные $90^\circ$, и отражениями квадратной решётки.

Орбита пары $(u,v)$ относительно этих автоморфизмов определяется
неупорядоченной парой модулей координат вектора $v-u$. Поэтому каждая орбита
пар является некоторым $D_{a,b}$. В шаре радиуса $r$ имеется лишь конечное
число таких орбит. Следовательно,

$$
B_R
=
D_{a_1,b_1}\lor\cdots\lor D_{a_s,b_s}
$$

для некоторого конечного набора пар $(a_\ell,b_\ell)$.

Это ещё не означает автоматически, что $B_R$ эквивалентно одному
$D_{a,b}$: для этого нужна отдельная лемма о конечных объединениях.

### 6. Лемма о конечном объединении

Пусть $B$ — непустое конечное объединение отношений $D_{a,b}$, содержащее
хотя бы один ненулевой шаг. Обозначим через $K$ конечное множество всех
допустимых векторов разности и положим

$$
L=\langle K\rangle_{\mathbb Z}.
$$

Тогда $L$ является решёткой достижимости отношения $B$.

Множество $K$ инвариантно относительно группы $D_4$ знаковых перестановок
координат. Поэтому $L$ также инвариантно относительно $D_4$. Покажем, что
существует $d\geq1$, для которого верно ровно одно из двух равенств:

$$
L=d\mathbb Z^2
$$

или

$$
L=dP.
$$

Для этого отождествим $\mathbb Z^2$ с кольцом гауссовых целых
$\mathbb Z[i]$. Инвариантность относительно поворота на $90^\circ$ означает
замкнутость $L$ относительно умножения на $i$, поэтому $L$ является идеалом
$\mathbb Z[i]$. Так как $\mathbb Z[i]$ — кольцо главных идеалов,

$$
L=\alpha\mathbb Z[i]
$$

для некоторого $\alpha\in\mathbb Z[i]$. Инвариантность относительно отражения
означает инвариантность относительно комплексного сопряжения. Поэтому
$\overline\alpha$ отличается от $\alpha$ умножением на обратимый элемент
$\pm1$ или $\pm i$. Отсюда $\alpha$ ассоциирован либо с целым числом $d$,
либо с $d(1+i)$. Эти два случая дают соответственно $d\mathbb Z^2$ и $dP$.

Рассмотрим компоненту нуля графа $B$. Она является связным графом Кэли

$$
\operatorname{Cay}(L,K).
$$

По теореме Морриса, Моррис и Верре каждый автоморфизм этой компоненты имеет
вид

$$
x\longmapsto Ax+t,
$$

где

$$
t\in L,
\qquad
A\in\operatorname{Aut}(L),
\qquad
A(K)=K.
$$

Линейный стабилизатор $K$ конечен: он действует точно на конечном порождающем
множестве $K$. Он содержит стандартную группу $D_4$, поскольку $K$ является
объединением полных $D_4$-орбит.

Используем следующий факт:

> Стандартная группа $D_4$ не содержится собственным образом ни в одной
> конечной подгруппе $\operatorname{GL}(2,\mathbb Q)$.

Действительно, усредним произвольное положительно определённое скалярное
произведение по конечной группе, содержащей $D_4$. Полученная форма инвариантна
относительно $D_4$, а потому является скалярным кратным стандартной евклидовой
формы. Следовательно, вся группа ортогональна в стандартных координатах.
Конечный порядок рационального поворота в размерности два может быть только
$1$, $2$, $3$, $4$ или $6$. Так как группа уже содержит поворот порядка $4$,
её подгруппа поворотов совпадает с циклической группой порядка $4$.
Добавление имеющихся отражений даёт ровно $D_4$.

Следовательно,

$$
\{A\in\operatorname{Aut}(L):A(K)=K\}=D_4
$$

и

$$
\operatorname{Aut}(\operatorname{Cay}(L,K))
=
L\rtimes D_4.
$$

Если $L=d\mathbb Z^2$, то такую же компоненту достижимости и ту же конкретную
группу автоморфизмов на ней имеет $DS_d$. Если $L=dP$, соответствующим
каноническим отношением является $DD_d$.

На всём множестве $\mathbb Z^2$ отношения $B$ и соответствующее каноническое
отношение имеют одинаковое разбиение на смежные классы решётки $L$. Их
автоморфизмы произвольно переставляют эти компоненты и независимо применяют в
каждой компоненте элементы $L\rtimes D_4$. Поэтому их конкретные группы
автоморфизмов совпадают.

После перехода к общему полному вверх расширению это равенство сохраняется.
По критерию Свенониуса для полных вверх структур получаем:

$$
B\equiv_{\mathrm{def}}DS_d
\quad\text{при }L=d\mathbb Z^2,
$$

и

$$
B\equiv_{\mathrm{def}}DD_d
\quad\text{при }L=dP.
$$

Здесь $\equiv_{\mathrm{def}}$ означает взаимную определимость без параметров.

### 7. Ограниченное отношение взаимно определимо с $B_R$

Определимость

$$
R\longrightarrow B_R
$$

уже следует из формулы, определяющей $B_R$ через $R$. Докажем обратную
определимость автоморфизмами полного вверх расширения.

По лемме о конечном объединении $B_R$ взаимно определимо с некоторым
каноническим отношением

$$
C\in\{DS_d,DD_d\}.
$$

Рассмотрим произвольный автоморфизм $q$ структуры
$\langle(\mathbb Z^2)^*,B_R^*\rangle$ и кортеж, для которого

$$
R^*(x_1,\ldots,x_m).
$$

Все различные значения этого кортежа лежат в одной компоненте графа $B_R^*$.
Автоморфизм $q$ переводит эту компоненту в некоторую другую компоненту. На
исходной компоненте его ограничение имеет вид

$$
q(x)=Ax+t,
\qquad A\in D_4,
$$

с учётом фиксированных идентификаций исходной и целевой компонент с обычной
квадратной решёткой. Это ограничение продолжается до изоморфизма обычных
решёток, заданного тем же переносом и той же знаковой перестановкой координат.

Поскольку $R$ определимо через $E$, оно сохраняется всеми переносами и всеми
элементами $D_4$. Один и тот же аффинный автоморфизм действует на все элементы
рассматриваемого кортежа, так как они находятся в одной компоненте. Поэтому

$$
R^*(x_1,\ldots,x_m)
\quad\Longrightarrow\quad
R^*(q(x_1),\ldots,q(x_m)).
$$

Применяя то же рассуждение к $q^{-1}$, получаем эквивалентность. Значит,

$$
\operatorname{Aut}((\mathbb Z^2)^*,B_R^*)
\subseteq
\operatorname{Aut}((\mathbb Z^2)^*,R^*).
$$

По критерию Свенониуса отсюда следует

$$
B_R\longrightarrow R.
$$

Вместе с ранее доказанной определимостью $R\longrightarrow B_R$ получаем

$$
R\equiv_{\mathrm{def}}B_R.
$$

Таким образом, всякое нетривиальное ограниченное многоместное отношение,
определимое без параметров через $E$, взаимно определимо с некоторым $DS_d$
или $DD_d$. Отношения, зависящие только от равенств между переменными,
относятся к нижнему классу определимости.

Этот результат не классифицирует произвольные неограниченные многоместные
отношения. Для них бинарное отношение совместной встречаемости $B_R$ может
оказаться неограниченным или даже полным и потерять локальную информацию,
содержащуюся в $R$.

## Выделение поведения на удалённой переменной

Пусть отношение

$$
R(\bar x,y)=R(x_1,\ldots,x_m,y)
$$

определимо через $E$, и пусть $r$ — радиус, полученный из теоремы Гайфмана
для фиксированной формулы, определяющей $R$. Положим

$$
s=2r+1.
$$

Введём вспомогательные условия

$$
\operatorname{Near}_s(\bar x,y)
\quad\Longleftrightarrow\quad
\bigvee_{i=1}^{m}\bigl(d_E(x_i,y)\leq s\bigr)
$$

и

$$
\operatorname{Far}_s(\bar x,y)
\quad\Longleftrightarrow\quad
\bigwedge_{i=1}^{m}\bigl(d_E(x_i,y)>s\bigr).
$$

Если $\operatorname{Far}_s(\bar x,y)$, то $r$-окрестность точки $y$
отделена от $r$-окрестностей всех элементов кортежа $\bar x$. Для любых двух
таких точек $y$ и $y'$ соответствующие отмеченные локальные окрестности
изоморфны с сохранением $\bar x$. Поэтому по теореме Гайфмана при фиксированном
$\bar x$ значение $R(\bar x,y)$ одинаково для всех достаточно удалённых
$y$.

Обозначим это общее значение через $R_{\mathrm{far}}(\bar x)$. Семантически
получаем

$$
\operatorname{Far}_s(\bar x,y)
\quad\Longrightarrow\quad
\bigl(R(\bar x,y)\longleftrightarrow R_{\mathrm{far}}(\bar x)\bigr).
$$

Непосредственная формула

$$
\exists y\,
\bigl(\operatorname{Far}_s(\bar x,y)\land R(\bar x,y)\bigr)
$$

не определяет $R_{\mathrm{far}}$ только через $R$, поскольку использует
$\operatorname{Far}_s$, а значит, отношение $E$. Эту цикличность можно
устранить подсчётом числа свидетелей.

В решётке $\mathbb Z^2$ шар радиуса $s$ содержит

$$
\lvert B_s\rvert=1+2s(s+1)
$$

точек. Поэтому множество точек, близких хотя бы к одному элементу
$\bar x$, имеет мощность не более

$$
N=m\bigl(1+2s(s+1)\bigr).
$$

Это равномерная оценка, зависящая только от числа свободных переменных и
формулы, но не от конкретного кортежа $\bar x$.

Рассмотрим два случая.

1. Если $R_{\mathrm{far}}(\bar x)$ ложно, то ни одна удалённая точка $y$ не
   удовлетворяет $R(\bar x,y)$. Следовательно, все свидетели $y$ находятся
   в объединении $s$-шаров вокруг $x_1,\ldots,x_m$, и таких свидетелей не
   более $N$.
2. Если $R_{\mathrm{far}}(\bar x)$ истинно, то $R(\bar x,y)$ выполняется для
   всех достаточно удалённых $y$. Таких точек бесконечно много, поэтому можно
   выбрать $N+1$ попарно различных свидетелей.

Отсюда получаем определение, использующее только $R$ и равенство:

$$
\begin{aligned}
R_{\mathrm{far}}(\bar x)
\quad\Longleftrightarrow\quad
\exists y_1\cdots\exists y_{N+1}\,
\Bigl(
&\bigwedge_{1\leq i<j\leq N+1}y_i\neq y_j\\
&{}\land
\bigwedge_{i=1}^{N+1}R(\bar x,y_i)
\Bigr).
\end{aligned}
$$

Таким образом, отношение, задающее общее значение $R$ на удалённых
реализациях последней переменной, определимо через $R$ без обращения к $E$:

$$
R\longrightarrow R_{\mathrm{far}}.
$$

Это пока не означает, что сами отношения
$\operatorname{Near}_s$ и $\operatorname{Far}_s$ определимы через $R$.
Полученный результат выделяет только значение $R$ на удалённой переменной.
Следующий этап состоит в анализе двух возможностей: различие между близким и
удалённым случаями либо существенно и позволяет восстановить ограниченное
отношение, либо исчезает после объединения случаев, и тогда переменную $y$
можно исключить.
